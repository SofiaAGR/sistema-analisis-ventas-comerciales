# Sistema de Análisis de Ventas Comerciales

## Descripción del Proyecto
Este proyecto es desarrollado como parte del Trabajo Práctico de la Unidad 4 de la materia Organización Empresarial de la Tecnicatura Universitaria en Programación.

El objetivo del mismo es analizar datos de ventas comerciales utilizando herramientas como Python, Git, GitHub, Jira y Google Colab, aplicando prácticas profesionales de control de versiones, trazabilidad y trabajo colaborativo.

## Escenario Seleccionado
Escenario B - Análisis de Ventas de una Pequeña Empresa.

## Tecnologías Utilizadas
- Python
- Google Colab
- Git
- GitHub
- Jira

## Estructura del Proyecto

```text
datos/
scripts/
resultados/
README.md
.gitignore
```

## Funcionalidades
- Lectura de datos de ventas desde archivos CSV.
- Cálculo de métricas comerciales.
- Generación de gráficos estadísticos.

## Ejecución
1. Clonar el repositorio.
2. Abrir el entorno en Google Colab.
3. Ejecutar el script ubicado en la carpeta `/scripts`.
